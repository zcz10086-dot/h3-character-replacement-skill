# 测试范围与交付限制

本报告区分本包工具实测、历史真实生产经验与尚未测试内容。不把mock通过写成新服务器生产通过。

## 已实测

- 主代理实际执行官方图保护单元回归：白名单字符串可改，未批准文本、数值值/类型、连接、节点集合变化拒绝。
- 用本项目成功的一采API载荷与批准模板比较：77节点执行结构和所有非字符串输入一致；载荷实例化工具保留原模板不修改。主代理独立验证真实77节点裸API模板可被批量工具规范包装，合法实际输出节点通过，不存在的输出节点拒绝。
- 项目配置预检：连续半开帧覆盖通过，镜头空洞、无理由保留原段拒绝。该工具检查文件存在，不冒充媒体解码。
- 视频工具合成回归：实际解码probe、切片和帧映射、联系图、软字幕流删除且音视频压缩流不变、ROI无损修复区域外像素保持、mask缺失拒绝、异常时间轴重建。主代理独立运行test_video_pipeline.py，12秒内退出0、status=passed；详见video-tests.json。
- 本项目真实SHOT11三窗90/85/83=258帧：连续PTS但异常sample duration1.708333秒被识别；用新工具重建322帧/30fps，PTS与sample duration异常清空，258源帧全部保留、最多2次映射。未将该私有视频打入包。
- 九个模型已通过官方仓库只读API解析出精确SHA256、大小和不可变commit，见assets/models.json；这是上游元数据核验，不是本轮下载权重或本地权重SHA实算。
- 云/批量工具离线和本机HTTP mock回归已通过：真实MP4流式下载并解码、expected_frames不符阻断、载荷保护、防重投与intent恢复、人工视觉和缓存双门禁、模型标记invalid状态、无关文件保护、安全解包、上传hash与账本锁等。结构化证据见cloud-tests.json；这不是实际远端SSH或GPU推理测试。

## 历史生产中已发生并验证的经验

本项目实际跑通云部署、9模型逐项校验、官方循环双采、及时下载、遮罩修补、真实前置上下文和原声合片。新工具是这些经验的可复用实现，不等于逐字复制旧脚本或已在新机复现全部链路。

## 尚未实测或不承诺

- 本包制作未重新租云机、安装远端环境、下载全部大模型或执行新GPU推理。全新系统下torch/CUDA/节点兼容必须由实际preflight与小样验收确定。
- 未把官方原包/工作流/插件源码或模型权重随包分发；操作者提供有权使用的官方包和批准API模板。本包不能凭节点名称自动复建官方复杂循环。
- VSR/STTN适配器只保证显式命令构造、路径与退出状态处理的测试；未重新运行真实高级GPU字幕模型。简单ROI空间修复不是复杂动态背景/遮脸文字的无痕保证。
- 人物参考生成、SAM3遮罩、身份和衣服审核需要实际素材和已有节点schema；当前提供制作操作卡与通用mask审计，不提供臆造的通用SAM3节点载荷。
- 近重复扫描需要对照原片静止段；技术检验和关键帧视觉抽验不是全片逐帧视觉认证。
- 字幕/水印处理不授予素材使用或标识移除权利；按用户已确认的素材和区域执行。

测试命令及准确报告路径以同目录教程为准。安装后首次使用先跑--help与本地测试，再用独立项目副本执行。
