# H3 人物替换制作

## 执行原则

先读 `references/tutorial.md` 判断当前阶段，再按需读视频与资产、云部署与生产说明。直接执行用户已授权的阶段；不把教程或准备完毕说成生产完成。所有命令均从本 Skill 的真实目录调用，不依赖启动工作目录。

- 官方工作流是只读权威输入。分别保存官方画布、经验证分组 API 模板和 SHA256；不通过手工重建图规避校验。默认仅替换经审阅的输入路径、提示文本及输出隔离路径，修改连接、class、数值等必须得到明确授权。
- 保留原视频参考输入、90 帧窗口、循环返回及 `ref_image_size=match`。核对实际模板，不凭节点编号或记忆猜连接。
- Picture 输入索引与项目人物身份固定；位置绑定以镜头审核结果为准，不根据生成外貌反推角色。人物服装取对应参考图。不要加入年龄猜测或原演员外貌特征。
- 禁止把 SSH 密码、令牌、私人参考图和原片写入 Skill 包。凭据使用环境变量或密钥。首次加入软件组件前说明新增内容和位置，遵守用户确认范围。
- 字幕、水印处理只对用户有权编辑的素材执行。原片保持只读；区分软字幕、烧录字幕、台标/水印和场景本身招牌，不默认擦掉所有文字。
- 技术成功不等于视觉通过。下载、帧数、模型哈希和任务 success 不能代替脸、服装、遮挡、身份及口型检查。

## 阶段与文件

1. **项目配置**：从 `assets/project.example.json` 建立项目副本。原片、参考图、镜头绑定、允许保留原段、输出和模板路径由项目决定。之前项目的镜头编号不能套用到新片。
2. **预处理**：执行素材探测；决定保留/关闭软字幕或对硬字幕、水印局部修复。先验证短片和区域外像素，再处理全片；复杂运动背景优先使用已获授权且已有的时序修复工具，不承诺简单图像修复无痕。详见 `references/video-and-assets.md`。
3. **资产**：以帧为单位切镜头，保留原帧与执行帧映射；制作参考图、人物位置绑定和遮罩。看连续转场、头脸、领口、肩衣、内孔、前景物体。实际制作步骤及已有SAM3适配边界见 `references/asset-review.md`。
4. **部署与模型**：读取 `references/cloud-and-production.md`，先 preflight。真实校验全部模型后，状态报告的 `valid=true` 且清单摘要匹配才是完成；失败可写 `valid=false`，不能凭标记文件存在进入生产。未验证的下载地址/节点版本不得冒充已验证。
5. **载荷检查**：对官方 API 模板做字段级差异报告。仅白名单输入字段可变。模板含循环的 API 载荷须来自实际成功导出，不把官方画布 JSON 直接当 `/prompt`。
6. **一采**：隔离项目/镜头/修订输出与缓存，提交前对账回执和队列。成功即下载为 `.part`，校验再原子改名；记录实际解码帧和输出窗口，之后备份 conditioning/latent。
7. **一采视觉验收**：生成首中尾、所有窗口交界前后及转场连续图。失败保留证据，只修确定问题；通过才写含 prompt_id、证据、检查帧和 reviewer 的 pass。
8. **二采**：确认当前修订一采缓存完整、身份通过，再提交对应二采。下载后重复技术与视觉检查。不能用旧修订 pass 批准新修订。
9. **合片**：逐窗口解码，按已确认执行帧率重建 PTS 和每帧持续时间，不能直接信任容器 duration。保全源有效帧；新增前置上下文仅在有明确映射时裁除。按原镜头帧数还原时间轴，原声直接取原全片，不逐段拼 AAC。
10. **交付**：对最终文件实际解码、检查时间戳和近重复停帧，核镜头边界与原片动作时间。说明抽验范围，不宣称未经进行的逐帧视觉认证。另存结果，用文件展示入口交付。

## 恢复与异常

- 网络断开或服务重启：先核 queue/history/输出/condition/latent，不能盲重投。历史消失并不等于远端输出不存在。保留旧回执及对账证据再恢复。
- 默认 Python 缺依赖时优先复用已验证绝对解释器；不要擅装另一套环境。`references/test-report.md` 记录本包实际测试范围。
- 遮罩遗漏：仅修证实缺漏另存版本，源视频像素不变。单帧缺罩也可留下原演员和工服。
- 每窗开头串人：检查提示词的“开头/随后”等是否被每窗口重复解释；以当前画面人数/位置绑定，不展开缺席人物外貌。
- 转场残留：先查原片和 mask。只有授权后才能加真实前置上下文；验证有效帧逐像素一致，完成后只裁新增帧，不删原有效帧。
- 停帧：检查 sample duration、PTS、容器时长及窗口实际帧数；详见 `references/troubleshooting.md`。总帧数相等不能排除中途停帧及尾部动作丢失。
- 口型差异：区分音轨偏移、全局时序、源执行映射及生成局部嘴形。无证据不要整体平移音轨。外加口型组件属新方案，须先说明并确认。

配置预检、工作流差异命令和视觉pass字段见 `references/acceptance.md`。`project.example.json`是项目总体模板；各执行工具的独立配置格式以对应教程和 `--help` 为准。

## 真实验证边界

本 Skill 提供可执行辅助工具和经生产总结的操作链。教程不是云端重部署验收。运行前读测试报告：仅将有真实命令输出与证据的步骤视为已验证；未进行的新服务器全新部署、付费 GPU 重采样与复杂字幕修复必须如实报告未测。
